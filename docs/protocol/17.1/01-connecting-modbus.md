# 1 Connecting Modbus

## 1.1 Connecting Modbus

The heat pump supports two Modbus protocols:

- Modbus RTU (connect to the BM-card (Port: MBe) located in the electrical cabinet)
- Modbus TCP/IP (connect to the RJ45 connection located on the display unit)

The settings for Modbus parameters can be found under Settings / BMS in the display.<br>
For Modbus TCP/IP, if you have secondary units, you will need a network switch or router since the primary/secondary interface uses the same RJ45 connector for its communication. Make sure that you are not using the same port as the Primary uses to communicate to its secondaries.
